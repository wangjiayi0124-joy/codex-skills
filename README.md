# Codex Skills

个人在产品工作与求职准备中持续沉淀的 Codex Skills。

## 当前收录

- `project-interview-deep-dive`：基于项目文档、PRD、截图、数据和真实口述事实，协作梳理项目面试档案；覆盖 STAR、真实面试追问路径、方案取舍、项目思考与复盘。
- `product-acceptance`：基于 PRD、链接、截图和需求材料，构建自适应的产品验收框架，并输出验收清单、问题清单和适合办公工具导入的交付物。

## 使用原则

- 每个 Skill 均以对应目录下的 `SKILL.md` 为入口。
- 以真实材料和实际验证为基础；不将假设、规划或未验证结论写成既定事实。
- Skill 是可持续迭代的工作流，后续会结合真实使用反馈继续完善。
